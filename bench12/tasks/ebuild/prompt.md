This directory is a packaging sandbox in the style of Gentoo Portage: `./pkgbuild` is a miniature ebuild runner (read RECIPES.md for the recipe API) and POLICY.md lists the review criteria every recipe must meet. The recipe `tinyhash-1.4.recipe` for the upstream tarball in distfiles/ does not build, and upstream's Makefile is hostile to packaging.

Make `./pkgbuild tinyhash-1.4.recipe` succeed AND meet every criterion in POLICY.md (the runner's own QA scan checks only some of them). Put changes to upstream build files in files/ as a patch applied from the recipe (or a sed in src_prepare); never edit distfiles/, Manifest, make.conf, pkgbuild, tools/, POLICY.md or RECIPES.md. The recipe must also behave correctly with USE="static-libs". No root, no network: everything happens inside this directory.
